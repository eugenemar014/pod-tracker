# PODS TRACKER

A cream-and-pink inventory, sales, client and due-date tracker.

## Included
- Dashboard
- Products / flavors / stock / prices
- Sales and automatic stock deduction
- Clients and balances
- Due-date tracking
- Fully editable columns
- Row checkboxes
- Search
- Low-stock alerts
- Login
- Excel-compatible CSV export
- Printable PDF-style reports through the browser print dialog
- SQLite database

## Run in Visual Studio Code
1. Install Node.js 20+.
2. Open this folder.
3. Run:
   npm install
   npm run install-all
   npm run dev
4. Open http://localhost:5173
5. Login:
   username: admin
   password: admin123

For a production build:
npm run build
npm start
